# Easylearn Institute — Next Build Notes

This package continues the PWA/Supabase version. It keeps the working authentication and real Students module.

The Master Blueprint defines the next backend modules as Courses, Batches, Attendance, Fees/Payments, Staff, Salary, Expenses and related reports. The current Supabase project already has core tables including institutes, profiles, students, teachers, batches, batch_students, fees, fee_payments, attendance, routines, expenses and salaries.

Important: the browser must only use the Supabase publishable key. Never put a service_role/secret key in this project.
