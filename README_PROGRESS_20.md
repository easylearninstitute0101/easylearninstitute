# Easylearn Institute — Progress 20

## Course Management

Course Management has been reviewed and hardened on top of the existing Progress 19 build.

Included:
- Supabase-backed course CRUD
- Tenant-scoped course access
- Course name, description, duration and BDT fee
- Active/inactive lifecycle
- Search by course name, duration and description
- Status filtering
- Duplicate course-name protection remains database-backed
- Non-negative fee validation in the UI
- Course data continues to feed Batch creation

This is a development milestone, not the final production release.
